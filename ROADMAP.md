# Roadmap

## Done
- Today dashboard: progress rings, next best action, live day balance, meal timeline, eating behaviour, trend, improvement suggestions.
- Nutrition: scan entry at the top, manual search and logging, daily completion, recipe browser, weekly view.
- Health: hydration, check-in, breathing reset. Coach with fixed rules.
- Profile, allergy filters, Focus-Friendly and Low-Energy modes, Reduce Motion, light and dark theme, data export and delete.
- 219 recipes with source and status fields; printable recipe book PDF.

## Next
1. Import sourced nutrition (for example MyFCD), map `data/ingredients_index.json`, and calculate recipe nutrition with verified gram conversions.
2. Replace the demo food values and demo targets with reviewed ones.
3. Replace drafted and outline recipes with verified recipes, starting with Sabah and Sarawak dishes.
4. Full onboarding and Bahasa Melayu localisation.
5. Real image recognition behind the existing scan interface.
6. Backend: accounts, database, object storage, notification scheduling.

## Later
Pantry and grocery list, wearables, professional reports.
